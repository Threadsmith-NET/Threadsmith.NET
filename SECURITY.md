# Security Policy for Threadsmith.NET

We take the security of Threadsmith.NET seriously. If you believe you have found a security vulnerability, please report it to us responsibly using the guidelines below.

## Supported Versions

We actively maintain and patch the current major version of this C#/.NET library. Older versions may not receive security updates.

| Version | Supported |
| :--- | :--- |
| Current (NuGet) | :white_check_mark: Yes |
| Legacy Versions | :x: No |

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security-related bugs.** Publicly disclosing a vulnerability makes your applications and other users vulnerable.

Instead, please report security vulnerabilities privately:
* **Email:** Send a detailed report to **mwright556@gmail.com**.
* **GitHub:** Alternatively, you can use the [GitHub Private Vulnerability Reporting](https://github.com) feature if enabled on this repository.

### What to Include in Your Report
To help us triage and fix the issue quickly, please include:
* A clear description of the vulnerability.
* The impact and how it affects the .NET runtime or application state.
* Step-by-step instructions or a minimal Proof of Concept (PoC) to reproduce the issue.

We will acknowledge receipt of your report within 48 to 72 hours.

## Disclosure Process

* **Fixing:** We will work to patch the vulnerability as quickly as possible.
* **Release:** A new version containing the fix will be published to NuGet.
* **Credit:** We will gladly credit you for your responsible disclosure in our release notes, unless you prefer to remain anonymous.
