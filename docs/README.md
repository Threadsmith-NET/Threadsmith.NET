# Threadsmith.NET Documentation

Start with the [user guide](user-guide.md) for installation, startup, commands, configuration, trust, tools, models, skills, extensions, MCP, and troubleshooting.

More focused references are grouped by audience:

- [Operations](operations/README.md) — day-to-day commands, configuration, lifecycle, providers, tools, skills, hooks, and release installation.
- [Extension authoring](extension-authoring/authoring-guide.md) — stable extension contracts and lifecycle guidance.
- [Skill authoring](skill-authoring.md) — declarative packages, schemas, workflows, verification, and distribution.
- [Architecture](architecture/README.md) — accepted decisions and subsystem contracts.
- [Testing](testing/fake-model-scripts.md) — deterministic fake-model scripts for integration tests.
- [Portable C# guardrails](guardrails/portable-csharp-guardrails.md) — repository coding requirements.

Implementation plans and feature proposals are repository planning material. They are intentionally excluded from installed release documentation because they can describe future rather than available behavior.
