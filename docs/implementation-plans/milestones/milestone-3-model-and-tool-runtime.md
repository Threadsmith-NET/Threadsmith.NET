## Milestone 3 — Model and Tool Runtime  *(plans 07, 08)*

**Status:** See the [authoritative milestone index](../milestones.md).
**Objective:** Support governed model-driven evidence collection.

**Deliverables:**
- Host-owned model abstraction.
- OpenAI-compatible provider.
- Model profiles and capability negotiation.
- Structured model output validation.
- Tool contracts and registry.
- Tool invocation pipeline.
- Read-only file, search, Git, process, and semantic tools.
- Permission evaluation.
- Tool activity and approval views.

**Exit criteria:**
- A model can request approved read-only tools.
- Tool results are typed, bounded, attributable, and persisted.
- Invalid tool arguments are rejected without executing.
- Model and process cancellation is functional.
- Tool activity is visible in the TUI.
