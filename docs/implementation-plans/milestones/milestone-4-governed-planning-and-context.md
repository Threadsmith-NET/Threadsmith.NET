## Milestone 4 — Governed Planning and Context  *(plan-09)*

**Status:** See the [authoritative milestone index](../milestones.md).
**Objective:** Replace transcript accumulation with explicit task and evidence state.

**Deliverables:**
- Task intent and acceptance-criteria model.
- Evidence store.
- Context assembler.
- Token estimator.
- Phase-specific context policy.
- Plan schema.
- Plan review and approval UI.
- Context inspector.
- Prompt asset versioning.

**Exit criteria:**
- A model can produce a structured implementation plan from selected evidence.
- The user can inspect why evidence was included.
- The plan can be approved, rejected, or revised.
- The model request does not depend on replaying the entire transcript.
