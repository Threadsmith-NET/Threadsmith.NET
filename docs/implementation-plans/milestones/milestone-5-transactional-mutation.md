## Milestone 5 — Transactional Mutation  *(plans 10, 11)*

**Status:** See the [authoritative milestone index](../milestones.md).
**Objective:** Safely apply reviewable changes.

**Deliverables:**
- Workspace baseline.
- File hashing and conflict detection.
- Mutation contracts.
- Text patch preview and application.
- Roslyn semantic mutation prototype.
- Diff generation and TUI diff view.
- Rollback.
- Mutation approval policy.
- Git worktree isolation option.

**Exit criteria:**
- A model can propose a bounded mutation set.
- The user can preview the exact diff before application.
- Setting to enable/disable preview of each change
- Conflicting file changes block application.
- Applied changes can be rolled back.
- No write occurs outside approved roots.
