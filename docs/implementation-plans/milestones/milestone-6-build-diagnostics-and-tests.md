## Milestone 6 — Build, Diagnostics, and Tests  *(plans 12, 13)*

**Status:** See the [authoritative milestone index](../milestones.md).
**Objective:** Close the coding loop with structured validation.

**Deliverables:**
- Baseline build capture.
- Affected project calculation.
- Structured build execution.
- Diagnostic normalization.
- Baseline vs. introduced classification.
- Diagnostic-to-mutation correlation.
- Test-project discovery.
- Filtered test execution.
- Test result normalization.
- Diagnostics and tests TUI views.
- Acceptance gate.

**Exit criteria:**
- The harness compiles affected projects after a mutation.
- Introduced diagnostics are distinguishable from baseline diagnostics.
- The harness runs a defensible test scope and explains the selection.
- Build and test failures can drive a bounded correction loop.
- The final result includes validation evidence.
