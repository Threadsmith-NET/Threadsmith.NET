===== Caligraphy2 =====
Modified by Paul Burton September 96 from caligraphy.flf as a demonstration of 
FigWin features.  Modification took about 5 minutes using FigWin's "rectangle 
search and replace" feature.  The characters previously consisted of only "*" 
characters.  These changes required two steps:

First, all instances of "*" were replaced with "#" to give the font a darker 
appearance.  

                         #                      /
Then, all instances of: #  were replaced with: /   (Each of these is a 
rectangle of four squares, including two blanks.)

Also added a period, exclamation point, and question mark and changed the 
default smushmode.

===== Graceful =====
Graceful-6x4 by Mikhael Goikhman, http://migo.n3.net/, 20/Jan/2002.

Why did I make this font? Most of the figlet fonts are ugly for my taste.
Chars ".", "'" or "|" are not as graceful as "(", ")", "/", "\" and "_".
Also most of the fonts unlike this one are either small or good, not both.
And finally, I wanted to have a strictly sized font, this one is 6x4.
I intended to create this elegant figlet font in 1996, but only in
January 2002 actually had the time to bring it to the working state. :)
Cyrillic letters are supported, maybe somewhen I will add hebrew latters.
To get a monospaced font 6x4, use "figlet -f graceful -m -1". Enjoy!

Permission is hereby given to modify this font, as long as the
modifier's name is added to this comment.

smpoison.flf figletized by Vinney Thai <ssfiit@eris.cc.umb.edu>
poison font composed David Issel <dissel@nunic.nu.edu>
date: Nov 18, 1994

Explanation of first line:
flf2 - "magic number" for file identification
a    - should always be `a', for now
$    - the "hardblank" -- prints as a blank, but can't be smushed
7    - height of a character
5    - height of a character, not including descenders
16   - max line length (excluding comment lines) + a fudge factor
-1   - default smushmode for this font (like "-m 0" on command line)
14   - number of comment lines
