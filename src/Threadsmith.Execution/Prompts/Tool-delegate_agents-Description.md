Runs 1-{{MaximumAgents}} children and returns their responses. Put independent assignments in one agents array so they can run concurrently within configured concurrency limits. Separate calls to this tool run sequentially, even when requested in the same response. Choose each child's role: explorer (default), implementer, securityReviewer, testReviewer, performanceReviewer, or architectureReviewer. The role adds system instructions and selects the configured model and permitted tools; it does not impose an answer format. Give each child a distinct objective and include relevant files, symbols, evidence, review scope, and constraints in context. Use readOnly for non-network inspection tools or inherit for eligible network-backed read tools. Every child in this tool is read-only, including implementer; children cannot edit files, invoke process/code-execution tools, delegate, select models, or transition the parent workflow.
