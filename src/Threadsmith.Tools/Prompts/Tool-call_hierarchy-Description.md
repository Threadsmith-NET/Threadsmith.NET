Primary compiler-aware tool for incoming or outgoing C# method-call relationships. Arguments use the flat shape {symbolId,direction?,depth?}; obtain symbolId from find_symbol. depth is the only model-visible traversal hint; host owns node/edge counts and time bounds. For call relationships, use this instead of text search; reuse a current symbolId when available, and use targeted fallbacks only when unavailable or incomplete semantic evidence leaves a question unresolved.
