Preferred starting point for broader C# repository exploration, architecture, debugging, execution-flow tracing, and cross-file impact questions. Ask a focused natural-language question, optionally anchored by known symbols or files. Returns bounded current line-numbered source grouped by file, with relevant multi-hop flow, dependencies, impact, coverage, and omissions. Use this to gather related source and compiler-backed relationships together instead of manually chaining broad text searches and file reads. Known files and symbols are useful anchors even when discovery is not needed. For one specific declaration or direct relationship, use find_symbol and the matching relationship tool; for an isolated file-content question, use read_file; for exact text without semantic relationships, use search. Treat returned source ranges as already read and do not reopen or re-search them. Keep query no broader than the user's request; maxFiles is optional, and traversal and result budgets are managed by the tool. Named C# files produce explicit missing or ambiguous results. Use list_files only to resolve a missing bare filename. Follow a reported granular continuation or fallback only when the missing evidence is needed to answer an outstanding question; incomplete coverage alone does not require another call. With no evidence, narrow the query or make one targeted lookup, not a broad inventory.
