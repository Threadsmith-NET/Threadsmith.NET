Lists every loaded project and its target frameworks, project references, and direct NuGet package references with declared versions and version sources. Also lists all centrally pinned package IDs from the repository's root Directory.Packages.props, including unused pins. Uses the host-selected .NET workspace; no path input, restore, or network query. Reports confidence and omissions. Does not report resolved or latest available versions. For available upgrades, use nuget_health in ConfiguredSources mode for a project, or run dotnet package list --project <solution-path> --outdated --format json when permitted. Inventory is useful afterward to locate central pins and project usage; it is not needed before a solution-wide outdated query.
