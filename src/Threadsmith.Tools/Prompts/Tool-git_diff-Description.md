Gets a host-bounded Git diff. Use mode WorkingTree for unstaged changes, Staged for index changes, Commit with baseRevision set to the commit/ref, and Range or MergeBase with both baseRevision and targetRevision. WorkingTree with baseRevision compares the complete current working tree against that revision. Use paths for up to 64 literal filters, mutually exclusive with path. Use includePatch=false for changed-path metadata without patch text; range endpoints are resolved to immutable revisions. contextLines controls patch context from 0 through 50 (default 3).
