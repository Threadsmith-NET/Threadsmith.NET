Fetch the tip of a source branch and optional comparison branch (depth 1, no tags, no history) into a new host-owned cache. Accepts an authorized credential-free HTTPS/SSH URL or configured remote name. Does not check out files or change the invoking repository. Host workflows use the returned cache path and refs as their authority-scoped context for ordinary Git inspection tools. This capability requires host admission and is not advertised to models. Requires current Git executable and network-host authority.
