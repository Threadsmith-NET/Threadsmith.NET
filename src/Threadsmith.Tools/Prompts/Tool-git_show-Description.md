Gets bounded commit, tree, tag, or blob content from local Git objects. Use paths for up to 64 distinct literal files at one revision; path and paths are mutually exclusive. Batch files include object identity, raw UTF-8 SHA256 digest, binary/truncation flags, and content when it fits. Oversized bodies may be omitted independently. Use inventory=true for normalized revision/tree metadata; inventoryOffset and inventoryMaximumEntries (1-500, default 200) page it using NextOffset. includeWorkingTree adds branch/default-branch metadata, a status digest, and tracked/untracked paths. In inventory mode, paths optionally restrict tree and working-path metadata to up to 64 literal paths. Set includeTrackedFiles=false to omit tracked files and read only revision/branch/status metadata plus untracked paths, before selecting changed files with git_diff. All paths remain subject to current read policy.
