Fast approved repository file inventory. Optional path selects a repository-relative directory; omitted, null, blank, or "." means the root. An explicit path inside the active scratchpad lists its files with paths relative to the scratchpad root; ordinary repository listings omit scratchpad contents. maximumEntries is a clamped hint; 0 uses the default. Use only to discover a path or when an inventory is requested; do not call before read_file for a known path. Scope to the narrowest likely directory and batch independent inspections.
