Inspects one repository project without changing packages. Offline mode reads existing restore assets for direct and transitive resolved dependencies, freshness, and omissions; it cannot identify available upgrades. ConfiguredSources mode queries host-configured trusted NuGet sources for vulnerable, deprecated, and outdated packages, including the latest available version in each outdated advisory. Results can be bounded or incomplete; check the completeness, truncation, and omissions fields. For a complete solution-wide upgrade listing, run dotnet package list --project <solution-path> --outdated --format json when permitted.
