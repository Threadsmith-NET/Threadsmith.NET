Reads an approved repository text file. Use startLine and maximumLines for a relevant section, including ranges located by search; omit them when a whole-file inspection is useful. The default starts at the beginning and returns up to 2,000 lines or 50 KiB, whichever comes first. Truncated results include nextStartLine for continuation. Read known files directly when their contents can answer the question. Batch independent file reads in one response.
