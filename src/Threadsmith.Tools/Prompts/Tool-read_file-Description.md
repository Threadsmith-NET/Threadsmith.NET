Reads an approved repository text, image, or PDF file. For a known path whose contents can answer the question, call directly without list_files, search, find_symbol, or code_explore. For a local edit or undo at a known location, use startLine and maximumLines to read the enclosing declaration and nearby context; do not request an entire large file when that section is sufficient. Omit the range when understanding the whole file is necessary. The default returns up to {{DefaultLines}} lines or {{MaximumContentBytes}} UTF-8 bytes; maximumLines supports {{MaximumLines}} and input files up to {{MaximumFileBytes}} bytes. Truncation includes nextStartLine. Batch independent reads. For exact UTF-8 pages use snapshot=true, continue at nextSnapshotOffset, and verify the stable whole-file contentDigest before relying on reassembly. Snapshot pages preserve line endings and the same bounds.

mode defaults to auto: PNG/JPEG images return validated metadata and pixels through the ordinary tool result. Use mode=image to require an image or mode=text to require text. Images do not support line ranges or snapshot options. Image limits: 5 MiB encoded, 8192 pixels per dimension, 16 megapixels. Locate plausible image filenames with list_files; image content is not text-searchable. The selected model must explicitly support Image input.

PDFs are detected in auto mode; use mode=pdf to require a PDF. A PDF returns rendered page images containing its text, scans and diagrams, not extracted source text. Use startPage (one-based, default 1) and maximumPages (default 1, maximum 4); continue at Pdf.NextStartPage until complete when the task requires more pages. Pdf.TotalPages and ordered Pdf.Pages identify coverage and page artifact IDs. PDF reads reject text range and snapshot options. Pages render at up to 144 DPI with a 1600-pixel longest edge and use ordinary Image input, context and artifact limits. Password-protected PDFs require an unlocked copy. The configured input-file limit applies to the original PDF.
