Reads an approved repository text file. Use startLine and maximumLines for a relevant section, including ranges located by search; omit them when a whole-file inspection is useful. The default starts at the beginning and returns up to {{DefaultLines}} lines or {{MaximumContentBytes}} UTF-8 content bytes, whichever comes first. maximumLines may request up to {{MaximumLines}} lines. The input file limit is {{MaximumFileBytes}} bytes. Truncated results include nextStartLine for continuation. Read known files directly when their contents can answer the question. Batch independent file reads in one response. Use snapshot=true for exact UTF-8 content pages instead of lines. Continue with snapshotOffset=nextSnapshotOffset until null; contentDigest identifies the whole source across pages. Check that digest remains stable and matches the reassembled content before relying on an exact snapshot. Snapshot pages preserve line endings and obey the same file/content bounds.
