Reads an approved repository text file. For a known path whose contents can answer the question, call directly without list_files, search, find_symbol, or code_explore. For a local edit or undo at a known location, use startLine and maximumLines to read the enclosing declaration and nearby context; do not request an entire large file when that section is sufficient. Omit the range when understanding the whole file is necessary. The default returns up to {{DefaultLines}} lines or {{MaximumContentBytes}} UTF-8 bytes; maximumLines supports {{MaximumLines}} and input files up to {{MaximumFileBytes}} bytes. Truncation includes nextStartLine. Batch independent reads. For exact UTF-8 pages use snapshot=true, continue at nextSnapshotOffset, and verify the stable whole-file contentDigest before relying on reassembly. Snapshot pages preserve line endings and the same bounds.
