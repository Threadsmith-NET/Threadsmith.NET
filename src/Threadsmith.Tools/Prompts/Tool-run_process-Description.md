Executes a {{ShellLanguage}} command in the repository root with bounded output. timeoutSeconds is a clamped nonnegative hint; 0 uses the default. Prefer dedicated inspection, Git, build, format, analyzer, test, and package tools; do not use shell commands merely to substitute for them. Use edit_source for targeted source edits and their reversal. Restoring a whole file with git checkout, git restore, or reset can discard unrelated uncommitted changes; do not use these commands as a substitute for reversing a specific edit. Whole-file restoration requires authorization for that scope and verification that unrelated changes will be preserved.

For custom scripting such as analyzing logs, transforming data, or computing results, use the in-memory C# host (`csharp_script`). Do not write or execute ad hoc Python, Bash, or PowerShell scripts, including inline scripts, for this work. Ordinary CLI commands and pipelines for authorized repository operations remain available through run_process; prefer dedicated tools when applicable. If csharp_script is unavailable and custom scripting is necessary, ask the user to enable it; continue independent work with available tools.
