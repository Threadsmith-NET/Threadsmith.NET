Prepare complete command examples and optionally validate supplied command-policy JSON without executing commands or changing configuration. Supply the current host platform, supported shell, intended machine or user layer, an existing absolute working directory, and 1–32 examples with stable unique IDs and explicit expected outcomes. Commands are limited to 8192 characters each and 64 KiB aggregate UTF-8; candidate JSON is limited to 64 KiB UTF-8. Omit policyJson for preparation only. Compilation uses an empty baseline and only the supplied candidate; active policy, installed defaults, and saved grants are not read. Each prepared action and the complete command are checked. An expected AlwaysDeny requires an explicit matching denial; unmatched/default denial and preparation failure never count as matches. Optional allowedExecutables checks only the selected outer shell basename; omission is unassessed. CandidateDigest identifies exact candidate UTF-8 bytes. ExampleSetId binds examples, context, supplied outer list, and observed native bindings. Copy validation facts exactly and preserve mismatches and unavailable outcomes. IsValidated means isolated example validation only, not authorization, execution, activation, installed-layer compatibility, or general safety. CoverageIncomplete results cannot support a validation claim. Diagnostics describe supplied-candidate failures; warnings identify broader argument scope, directory descendants, script-content limits, alias binding limits, and path replacement races.
