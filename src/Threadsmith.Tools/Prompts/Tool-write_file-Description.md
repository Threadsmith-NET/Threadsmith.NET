Save a UTF-8 report or text/data artifact directly. Use for .txt, .md, .markdown, .json, .csv, .tsv, .yaml, .yml, .xml, .log, and .rst artifacts, not code or project configuration. The host enforces tools.writeFile.allowedFolders; the default is .inbox under the active repository. Other folders require configuration, and absolute paths work only inside a configured absolute folder. Parent folders are created as needed. Supply path and either content or useLastResponse:true. When asked to save your previous report/answer, prefer useLastResponse:true: the host copies the latest archived assistant answer in this session exactly, without regenerating it. Existing files are preserved unless overwrite:true is explicitly requested. Content is limited to {{MaximumContentBytes}} UTF-8 bytes. Git metadata, Threadsmith settings, instruction files, and symbolic links/junctions are prohibited. A denial does not authorize writing the same path through a shell or another tool. Example: {"path":".inbox/report.md","useLastResponse":true}.

To export a validated image, supply artifactId from this session instead of content or useLastResponse. The destination must end in .png for PNG or .jpg/.jpeg for JPEG. The host copies exact bytes without regenerating or resizing them. User-message attachments metadata lists artifactId values in the same order as the attached images, including retained prior user messages. Generated image IDs are reported in generatedImages metadata after successful output admission. Image input capability does not imply image generation; the current compiled endpoints do not offer native image output.
