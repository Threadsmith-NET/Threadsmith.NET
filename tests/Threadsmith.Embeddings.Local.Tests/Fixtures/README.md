# Local embedding fixtures

The checked-in JSON contains only synthetic test text. `production-reference-parity.json` records finished vectors from the user-supplied `MpnetEmbedderEngine`, as used by `MlNetAllMiniLML12V2` with 384 dimensions and maximum sequence length 256. The reference source was compiled unchanged, with ONNX Runtime 1.23.0 and Microsoft.ML.Tokenizers 2.0.0-preview.1.25127.4. Its SHA-256 is `97e23f75fbb593c8247c7ac2c1391c0678d7fcd48b92c1ffd4b4619e42ca304a`. Model and vocabulary hashes match the immutable artifacts in `src/Threadsmith.Embeddings.Local/minilm-assets.json`.

The production adapter preserves the reference's built-in BERT options and default `EncodeToIds` framing followed by another manually added CLS/SEP pair. These four boundary tokens count toward the complete 256-token limit: 252 ordinary content tokens fit; 253 report overflow. Do not silently replace this behavior with a single pair or a Hugging Face tokenizer. The engine returns all finished float32 mean-pooled, L2-normalized components; the provider performs no further vector transformation.

Ten samples cover empty text, case/punctuation, accents, CJK/emoji, literal special tokens, newline/tab behavior, full input and overflow. Expected IDs/masks contain attended tokens; expected vectors come directly from the original fixed-256-padding inference. The product uses dynamic attended length and bounded two-thread inference, retains its already-pinned ONNX 1.22.1/Tokenizers 2.0.0 dependencies, and compares every component with maximum absolute tolerance 0.00005 for CPU architecture rounding. On the validation host, all 127 independently probed canary, model-written-note, query, calibration and boundary vectors matched the original exactly. This observation is not a guarantee of bit identity on every supported CPU.

To regenerate offline, provide the exact authorized reference engine source and pre-staged assets. This explicit utility requires .NET 10 and the reference's two exact NuGet package versions already cached. It does not download dependencies/assets or reference/build the product implementation; ordinary tests need neither the external repository nor these reference packages.

```powershell
./tests/Threadsmith.Embeddings.Local.Tests/Fixtures/generate-reference.ps1 -ReferenceEnginePath '<reference checkout>/LocalEmbeddingsModel/MlNet/MpnetEmbedderEngine.cs' -AssetsPath artifacts/embedding-assets/embeddings/all-MiniLM-L12-v2
```

The utility verifies the source hash before compilation and asset hashes before inference, links the original source unchanged, and writes provenance with the vectors. `production-reference-texts.json` owns the synthetic input list; `ReferenceFixtureGenerator.cs.template` only inspects original token tensors and records the engine's finished results. Changing goldens requires reviewing source, package, asset and transformation identities. The former Python/Hugging Face reference fixture is superseded by this production reference.

`retrieval-fixture.json` version 1 freezes eight notes and twenty requests, split into nine calibration and eleven held-out examples. The previous implementation pinned the semantic minimum at 0.47. The adaptation retains that existing value and requires it to remain optimal on calibration: minimize twice false inclusions plus missed relevant memories, then minimize misses. The current optimum plateau is 0.46–0.53. The report also records the previous highest-threshold tie-break result, 0.53, as an alternative, not the runtime selection. Raising the cutoff to that alternative would miss the held-out FindSymbolAsync paraphrase (cosine about 0.518). The held-out and larger realistic-note fixtures evaluate the retained cutoff; neither selects it. This policy refinement and the alternative result are explicit so the adaptation is not presented as a new blind threshold selection.

Normal test discovery never accesses online services or downloads models. Set `THREADSMITH_EMBEDDING_INTEGRATION=1` to run offline native parity/cancellation/retrieval tests. `THREADSMITH_EMBEDDING_REPORT` optionally writes raw timings, rankings, calibration candidates, retained and highest-equivalent minima to a scratch JSON file. Timing checks report evidence without asserting universal speed. The reference development-host budget is 25 ms p95 for one uncached retrieval plus inclusion receipt on the small fixture; it is not a 256-token worst-case SLA. Maximum-length and slower-host measurements must be reported separately.
